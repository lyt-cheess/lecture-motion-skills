# 讲解角色动效

让用户角色围绕教学对象表演。先检查原图、分层和本次任务，复用已确认的外观、衣着和配件。新角色默认复用动作意图与时序，按身体比例重设锚点；缺少部位时跳过对应动作，不假设任意PNG都有完整骨骼。

## 动作与插入时机

| 动作 | 表演目的 | 典型位置 |
| --- | --- | --- |
| 讲解 | 先看目标、转头，再用教鞭或手指指向 | 关键图解旁 |
| 帮助记忆 | 提醒、点头、依次指向少量要点 | 知识点recap |
| 灵感 | 思考、停顿，发现答案后舒展或轻跳 | 引入新思路 |
| 强调 | 靠近、前倾或点一次重点，随后停留 | 定义与区别 |
| 警告 | 停步、抬掌、后撤，警示对应具体错误 | 易错点与边界 |
| 出入场 | 预备、移动、落地缓冲、回头或挥手 | 片头片尾 |

每种新动作先交独立动态小样，审核后再嵌入课程。角色可从侧边、上方或图解目标附近出现，不固定在下方晃动；大小、遮挡与空间路线按镜头检查。用户指定的眼镜教鞭姿态不能改成摊手。

## 原图与连续动作

`assets/`保存原图，`actor.js`是可运行的取帧与二维形变预演，`index.html`用于五种动作独立审核。这是可编辑起点，不代表自然动作已经验收。

图集通常只有关键姿态。先校准头、脚底、手部和画布锚点；不要高速轮播整张姿态图。大幅表演优先采用分层关节、足够过渡帧和清楚的动作弧；单张图片微形变不能代替完整表演。

头、躯干、手臂、脚、配件与可选尾巴/耳朵分开控制。指向目标用稳定坐标。手势有预备、执行与回收，脚落地有支撑，耳朵尾巴稍后停下。循环检查末尾到开头的衔接。

眼镜、教鞭单独处理。换头时清理旧轮廓，检查双耳、双脸与残影，不能用新头覆盖仍存在的旧头。取帧核对耳尖、尾巴、教鞭、鞋子，避免裁入相邻姿态或半个装饰。

## 声音与交付

角色声音与旁白分开。没有实际声音时可做身体和手势预演，不伪造已经对齐的嘴形。音频完成后按角色台词的真实语义锚点驱动口型与强调动作。

交付原素材、部位与锚点说明、组件、逐项预览和实际检查。先独立审核角色，再接入已通过画面。当前老师动作需要继续改善，不能因画面通过就把角色也标为通过。
