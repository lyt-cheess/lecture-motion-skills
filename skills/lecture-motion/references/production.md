# 实现与审片

分镜记录采用最小结构。每段写 `source_anchor`、`shot_id`、讲解目标、对象前后状态、触发词与暂定时段。多个口播段可以落在同一镜，重点动作仍用独立锚点。启用角色时，给出可选动作版本和构图里的站位，动作细节在角色模块维护。审片时检查进出路线、脚步和图解净空。

实现时重用已运行的播放器和工程入口。镜头多时按章节组织场景，统一入口把全片时刻换成章节内时刻。台词、镜头与动作从同一时间数据读取。优先复用现有绘制函数，出现稳定的重复再提取组件。色板和背景集中配置，画幅变化时重新排版及测量文字。

用一组可追踪的对象贯穿相关镜头。一段运动可拆为准备、移动、落定三个时段，适当错峰以指明顺序。保持主要结果的阅读时间，以画面上的先后关系表达“先算什么、再用什么”。用大图形和必要符号建立视觉焦点。矩阵、公式、代码按具体需要出现。标题、说明、节目名和镜头编号留在文稿元数据。默认浅底紫绿，口播字幕为底部纯黑单行。

逐章在真实预览检查文字、裁切、状态切换和数字；跨章回看对象位置的承接。用乱序调用同一时刻检查确定性，再看连续动作。检查记录区分静帧、连续播放与实际试听。有实录后按新时间戳校准。独立画面工程可以先交无声预演。


## v3 的制作顺序与回归方法

- **保住运动。** v3 沿用了 v2 已确认的连续运动。把英文词移到四列，在同一屏发展出输入表示、三路投影、匹配、权重和汇总。使用曲线、对象位移、错峰包络和缓动，不用一次性替换整张布局。
- **在运动上加解释。** 投影时出现矩阵与投影公式，点积和 V 汇总才插入对应的短代码。结果留出可读时间。拿掉解释层连播一次，检验主体本身能否讲清关系。
- **补角色与字幕。** 适时接入原图角色。由同一份时间数据决定正文、动作和字幕。字幕纯黑，1080 宽从 42 px 起步，按安全区实测，溢出时拆成短句。没有录音的版本仍按当前稿显示字幕。
- **先同稿对照，再迁移。** 用已确认 v3 的原工程和原时间轴跑回归。抽查 3.7、9.8、15.5、20.2、24.4、27.8、33.8 和 38.4 秒，比对未改动场景的像素。新题用相同方法检查对象是否跨镜继承、变化是否按口播次序发生、关键处是否有足够阅读时间。以实际导出的正常速度连播验收，分别记录帧、字幕、播放和声音状态。
