# A 版｜Transformer v3

原 40 秒画面基准，时长 40 秒，竖屏 1080×1440。底部有字幕，时间轴为无声预演编排。源码保留原场景和时间轴，素材路径按仓库目录调整。

从独立仓库根目录执行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8080/skills/lecture-motion/examples/transformer-v3/watch.html`。同服务下，`/skills/xixi-motion/index.html` 可单独预演曦曦的动作。
